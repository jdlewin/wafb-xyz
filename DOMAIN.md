# wafb.xyz — Cloudflare Pages domain stub

- Custom domain: `wafb.xyz`
- DNS: CNAME `wafb.xyz` → `<project>.pages.dev` (in Cloudflare DNS, proxied).
- Pages project: framework preset Astro, build `npm run build`, output `dist`.
- TLS: Cloudflare automatic. No config in repo; this file documents intent.
